# Ақпараттар және кодтау теориясы — 1-нұсқа

Бұл репозиторийде екі практикалық тапсырманың Python тіліндегі шешімі бар.

## Файлдар

- `prefix_code.py` — префикстік код, Фано шарты және декодтау.
- `hamming_code.py` — (7,4) Хэмминг кодын құру, синдром арқылы бір биттік қатені анықтау және түзету.

## Іске қосу

Python 3 орнатылған болуы керек. Терминалда файл тұрған бумаға өтіп, командаларды орындаңыз:

```bash
python prefix_code.py
python hamming_code.py
```

## 1-тапсырма нәтижесі — префикстік код

- Алфавит көлемі: 23 символ.
- Ең аз біркелкі екілік код ұзындығы: 5 бит.
- `0110110111` хабарының декодталған нәтижесі: `A C C D`.

## 2-тапсырма нәтижесі — Хэмминг коды

- Ақпараттық комбинация: `0100`.
- Дұрыс кодтық комбинация: `1001100`.
- 3-разряд бұрмаланғаннан кейін: `1011100`.
- Синдром: `011₂ = 3₁₀`.
- Қатені түзеткеннен кейін: `1001100`.
